# Distribution and licensing

This is a private application build. No public distribution license has been selected for the original application code or authored lesson content. Choose one explicitly before an open-source release; `package.json` remains private.

The source textbook, original scan, publisher marks and source illustrations are not included and are not relicensed. Newly authored explanations and factual teaching do not represent permission to redistribute the original scan. Keep `.local/`, PDF files and credentials excluded from Git and public hosting. A content-rights review is still needed before external distribution.

Open-source dependencies retain their own licenses. Manrope and DM Sans are self-hosted from Fontsource under OFL-1.1; their license notices are shipped in public/licenses/ and in the installed font packages. Lucide icons and all other dependencies retain their respective notices. Generated PWA icons are original code-drawn artwork. No externally sourced photo or textbook illustration is used.
