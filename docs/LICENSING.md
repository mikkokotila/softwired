# Distribution and licensing

This repository may be made public for source visibility, but that is NOT a grant of an open-source license for the application code or authored lessons. No public distribution license has been selected for the original application code or authored lesson content. Choose one explicitly before an open-source release; `package.json` remains private.

The source textbook, original scan, publisher marks and source illustrations are not included and are not relicensed. Newly authored explanations and factual teaching do not represent permission to redistribute the original scan. Keep `.local/`, PDF files and credentials excluded from Git and public hosting. A content-rights review is still needed before external distribution.

Open-source dependencies retain their own licenses. Manrope and DM Sans are self-hosted from Fontsource under OFL-1.1; their license notices are shipped in public/licenses/ and in the installed font packages. Lucide icons and all other dependencies retain their respective notices. Generated PWA icons are original code-drawn artwork. No externally sourced photo or textbook illustration is used.

## Public Pages pilot

The original scanned source textbook, illustrations, OCR and local private files are not distributed. The independently authored lesson texts and prompts are shared as part of a user-authorized public pilot; no rights to the original work or publisher material are asserted. Content-rights and teacher reviews remain pending. Do not treat public repository visibility as a license to reuse the lessons or original textbook. If authorization to publicly distribute any content is lacking, remove that content promptly.
